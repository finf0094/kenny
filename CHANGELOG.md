# Changelog

## 0.2.0

### Изменения, требующие внимания

- Встроенные подписи компонентов теперь **английские по умолчанию**. Чтобы вернуть русские,
  добавьте `provideKnLabels(knLabelsRu)` из `@kenny/ui/core` в конфигурацию приложения.
- Базовый стиль стал глубже: фон страницы чуть темнее листов (`--kn-color-canvas`), у карточек
  появилась мягкая тень (`--kn-elevation-card`), у закрашенных контролов — блик
  (`--kn-shadow-highlight`), у поля в фокусе — мягкое свечение (`--kn-field-halo-width`). Любое из
  этих значений возвращается одной переменной.
- Дорожка Progress и Slider использует новый токен `--kn-color-track`.

### Новое

- **Локализация**: `provideKnLabels()`, наборы `knLabelsEn` и `knLabelsRu`, частичное
  переопределение, набор-сигнал для смены языка на лету.
- **Компоненты**: Alert, Chip, Divider, Toggle Group, Number Input.
- **`@kenny/ui/motion`**: `KnNumber` (число со счётом), `KnReveal` (появление при прокрутке),
  `KnRipple` (волна для своих элементов).
- **Движение**: волна от нажатия во всех нажимаемых компонентах (`--kn-ripple-opacity`), темп всей
  системы (`--kn-duration-scale`), панель вкладки приезжает со стороны выбора, пульсирующая точка
  у Badge (`pulse`), keyframes `kn-ping`, `kn-shake`, `kn-shift-in`, `kn-zoom-in`.
- **Токены**: `--kn-color-thumb`, `--kn-color-track`, `--kn-field-shadow`,
  `--kn-field-halo-width`; блок с `data-kn-preset` перечитывает и шрифт.
- **Конструктор стиля**: шрифт, темп, отклик на нажатие, предпросмотр в обеих темах, ссылка на
  собранный стиль.

## Не выпущено

### Изменения, требующие внимания

- Границы контролов стали заметнее: обводка полей, рамка флажка и радио, дорожка выключенного
  переключателя теперь дают контраст не меньше 3 : 1 во всех стилях и темах (WCAG 1.4.11). Цвет
  задаёт новый токен `--kn-color-control-border`; прежний, более светлый вид возвращается им же.
- В стилях «Мягкий» и «Стекло» у полей появилась обводка — одной заливки было недостаточно.

### Новое

- `pnpm check:contrast` — измерение контраста границ контролов в браузере; входит в CI.
- `pnpm check:visual` и workflow для pull request — сравнение скриншотов «до и после».
- Аудит доступности дополнительно проходит все страницы в письме справа налево.
- Темп у части страницы: атрибут `data-kn-tempo` (`brisk`, `calm` или своё значение
  `--kn-duration-scale`); всплывающие слои наследуют темп блока, из которого открыты.
- Переменные `--kn-checkbox-border` и `--kn-radio-border`.
