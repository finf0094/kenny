# @kenny/tokens

Дизайн-токены Kenny в виде CSS custom properties: цвет (светлая и тёмная темы), поверхности и
их край, форма, плотность, типографика, тени, z-index и motion. Без JavaScript.

```css
@import '@kenny/tokens/kenny.css'; /* токены + базовые стили страницы */
/* или по отдельности */
@import '@kenny/tokens/tokens.css';
@import '@kenny/tokens/base.css';
```

Значения по умолчанию — нейтральный базовый стиль. Тема выбирается атрибутом
`data-theme="light" | "dark"` на любом элементе; без атрибута используется системная.

## Стили

Пресет — файл, который даёт тем же токенам другие значения. Подключите его после токенов и
поставьте атрибут на `<html>` или на любой блок.

```css
@import '@kenny/tokens/presets/glass.css'; /* или tonal.css, crisp.css, soft.css */
```

```html
<html data-kn-preset="glass"></html>
```

| Файл        | Характер                                                                |
| ----------- | ----------------------------------------------------------------------- |
| —           | Базовый: непрозрачные листы, тонкие рамки, поля с обводкой              |
| `glass.css` | Полупрозрачные поверхности с размытием, блик по кромке, кнопки-капсулы  |
| `tonal.css` | Поверхности — оттенки акцента, поля с линией снизу, без рамок           |
| `crisp.css` | Плотный интерфейс для данных: малые радиусы, контролы ниже, шрифт 14 px |
| `soft.css`  | Группы без рамок на сером фоне, крупные контролы и переключатели        |

`presets.css` содержит все пресеты сразу — для переключения стиля на лету. Свой пресет — такой же
CSS-файл: `[data-kn-preset='имя'] { --kn-radius-md: 4px; … }`.

`tokens.json` содержит список токенов в машиночитаемом виде.
